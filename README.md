## 🌟 Overview
This repository contains a fully responsive, interactive digital resume built entirely with vanilla web technologies. It is designed to be lightweight, incredibly fast, and deployable to any static hosting provider (like GitHub Pages or Netlify) with zero configuration.

## 🚀 Key Features
- ⚡ **Zero Dependencies:** No frameworks, no build tools. Just pure HTML, CSS, and JS.
- 📱 **Fully Responsive:** Adapts seamlessly to mobile, tablet, and desktop screens.
- 🎨 **Custom Styling:** Clean, professional aesthetic built with vanilla CSS.
- ⚙️ **Interactive Elements:** Smooth animations and interactions powered by lightweight JavaScript.

## 🛠️ Technology Stack
- **Structure:** HTML5
- **Styling:** CSS3 (Vanilla)
- **Logic:** JavaScript (ES6+)

## 📦 Getting Started
1. Clone the repository.
2. Open index.html in your web browser.
3. No installation or build steps required!
