# Resume - AI Build Blueprint

This repository contains a static HTML/CSS/JS digital resume or portfolio page.

## Goal
To maintain a high-performance, visually striking digital resume that requires zero build steps and can be hosted on any static file server.

## Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript.
- **Architecture:** Monolithic static files.

## AI Guidelines
1. Do not introduce build tools (like Webpack or Vite) or framework dependencies (like React) unless explicitly requested. The beauty of this repository is its simplicity.
2. Ensure CSS updates maintain responsiveness across all devices (mobile, tablet, desktop).
3. JavaScript logic (\script.js\) should remain modular and free of heavy libraries (e.g., jQuery) to ensure maximum performance.
4. Keep the \.ai_build_plan.md\ in the repository for ongoing architectural context.
